# digitalplay Design

Grids, colour and type for posters, pages and things people actually read.

Part of **[digitalplay.work](https://digitalplay-work.netlify.app)**, a free collection of playful creative tools from the **Loose Parts Collective**. Every tool is a single HTML file that works offline, takes your own inputs, explains itself in a LEARN panel, and lets you save presets.

| Tool | What it is | Try it |
|---|---|---|
| [Grid Kit](tools/grid-kit.html) | A poster maker built on a modular grid. Type your own words, set columns, rows, margins and a type scale, then drag blocks between grid cells until the layout clicks. | [Play](https://digitalplay-work.netlify.app/play/design/grid-kit.html) |
| [Palette Lab](tools/palette-lab.html) | Build a colour palette from one colour you like or from a photo of your own, then check every pairing for readable contrast before you use it. | [Play](https://digitalplay-work.netlify.app/play/design/palette-lab.html) |

## Use it

- **Online:** follow a Play link above.
- **Offline:** download the repo (green Code button, then Download ZIP) and double-click any file in `tools/`. Nothing needs installing and nothing is sent anywhere.

## Every tool has

- **LEARN** (press <kbd>L</kbd>): the idea, a little history, things to try, keyboard keys.
- **PRESETS** (press <kbd>P</kbd>): save your settings in this browser, export them as JSON, import a friend's.
- No tracking, no cookies, no account, no AI unless you ask for it.

## Catalogue

`catalogue.json` describes every tool with the facets the hub uses (skill level, what you bring, what you take away, era, session length, AI). It follows `catalogue.schema.json`.
