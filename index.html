digitalplay Design

Grids, colour and type for posters, pages and things people actually read. Part of digitalplay.work.

  • Grid Kit
    A poster maker built on a modular grid. Type your own words, set columns, rows, margins and a type scale, then drag blocks between grid cells until the layout clicks.
  • Palette Lab
    Build a colour palette from one colour you like or from a photo of your own, then check every pairing for readable contrast before you use it.
